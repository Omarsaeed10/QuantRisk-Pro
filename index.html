MAT231 Course Formula Reference

1. Continuous Random Variables (PDF & CDF)

  • Probability Density Function (PDF): \(f(x) \ge 0\), \(\int_{-\infty}^{\infty} f(x) dx = 1\)
  • Probability Calculation: \(P(a \le X \le b) = \int_{a}^{b} f(x) dx\)
  • Cumulative Distribution Function (CDF): \(F(x) = P(X \le x) = \int_{-\infty}^{x} f(t) dt\)
  • Expected Value (Mean): \(\mu = E[X] = \int_{-\infty}^{\infty} x f(x) dx\)
  • Variance: \(\sigma^2 = \text{Var}(X) = E[X^2] - \mu^2\)

2. Normal & Standard Normal Distribution

  • Normal PDF: \(n(x; \mu, \sigma) = \frac{1}{\sigma\sqrt{2\pi}} e^{-\frac{1}{2\sigma^2}(x-\mu)^2}\)
  • Standard Normal Transformation: \(Z = \frac{X - \mu}{\sigma} \sim \mathcal{N}(0, 1)\)
  • Standard Z Values: \(P(-1.96 < Z < 1.96) = 0.95\) (95% CI)

3. Central Limit Theorem & Confidence Intervals

  • Sampling Distribution of \(\bar{X}\): \(\mu_{\bar{X}} = \mu\), \(\sigma^2_{\bar{X}} = \frac{\sigma^2}{n}\)
  • Standard Error: \(SE = \frac{s}{\sqrt{n}}\)
  • 95% Confidence Interval for Mean \(\mu\): \(\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\) (\(z_{0.025} = 1.96\))
  • 95% Chi-Square CI for Variance \(\sigma^2\): \(\frac{(n-1)s^2}{\chi^2_{\alpha/2}} < \sigma^2 < \frac{(n-1)s^2}{\chi^2_{1-\alpha/2}}\)
